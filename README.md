# textkit

## วัตถุประสงค์

ชุดฟังก์ชันสำหรับจัดการข้อความ พัฒนาโดยนักศึกษาจำนวน 4 คน เพื่อฝึกการทำงานร่วมกันด้วย Git และ GitHub

## การติดตั้ง

ต้องใช้ Python 3.12 ขึ้นไป

## การใช้งาน

```bash
python main.py
```

### caser.py (สมาชิก 4)

ฟังก์ชัน `capitalize_words(text)` ทำให้ตัวอักษรแรกของแต่ละคำเป็นตัวพิมพ์ใหญ่

ตัวอย่าง: `capitalize_words("hello first year")` ได้ `"Hello First Year"`
